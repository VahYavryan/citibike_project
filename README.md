# Citi Bike Jersey City Data Analysis Project

This project focuses on analyzing Citi Bike trip data from Jersey City using Python. The analysis covers the entire pipeline: from data acquisition and cleaning to weather integration, data visualization, and neighborhood-level geospatial analysis.
